# История Средних веков — тренажёр для 6 класса

Сайт-тренажёр по учебнику «Всеобщая история. История Средних веков. 6 класс».

Ребёнок выбирает главу и параграф, проходит тест. Если отвечает неверно — сразу видит свою ошибку, правильный ответ и короткое пояснение, а сам вопрос возвращается в очередь на случайное место среди оставшихся. Тест заканчивается только тогда, когда на все вопросы дан верный ответ.

## Что внутри

- **22 теста** — по всем параграфам учебника (введение + 24 параграфа, часть из них сдвоенные).
- **632 вопроса** с 4 вариантами ответа и пояснением к каждому.
- Все ключевые даты из синхронистических таблиц «МИР» и «РОССИЯ» в начале параграфов, а также основные понятия и исторические личности.

## Как работает тест

1. Вопросы и варианты ответов каждый раз перемешиваются.
2. Верный ответ — вопрос уходит из круга навсегда.
3. Неверный ответ — сразу показывается разбор, а вопрос возвращается на случайное место среди оставшихся (не следующим, чтобы ответ не запоминался механически).
4. В конце — похвала и статистика: сколько вопросов, ошибок и минут.
5. Пройденные параграфы отмечаются галочкой (хранится в браузере, `localStorage`).

## Запуск

Сайт статический, сборка не нужна. Локально:

```bash
python3 -m http.server 4173
```

и открыть `http://localhost:4173`.

## Структура

```
index.html        — список глав и параграфов
test.html         — страница теста
assets/style.css  — стили, мобильная вёрстка, анимации
assets/app.js     — главная страница
assets/quiz.js    — движок теста
data/index.json   — оглавление учебника
data/q/*.json     — вопросы по параграфам
```

## Как добавить или изменить вопрос

Открыть нужный файл в `data/q/` и отредактировать. Формат:

```json
{
  "q": "Текст вопроса",
  "options": ["Верный ответ", "Неверный", "Неверный", "Неверный"],
  "correct": 0,
  "explain": "Пояснение, которое покажется после ответа"
}
```

`correct` — индекс правильного варианта в массиве `options` (нумерация с нуля). На странице варианты всё равно перемешиваются, поэтому правильный ответ можно оставлять первым.
